# Security

VisionCtx binds proxy and dashboard to loopback. It never stores request auth headers. When an incoming request has no credential header, the proxy can forward its process's `ANTHROPIC_API_KEY` from memory. Raw request/response bodies are not persisted. Safe text blocks are available for inspection from a bounded 16 MiB in-memory cache until eviction or restart. Disk source capture is off by default; when enabled, only blocks with no detected secret pattern are written. Image rendering rejects detected sensitive blocks. Diagnostic views recursively redact common keys and token formats and omit base64 `data` values.

Pattern detection is not a proof of absence of secrets. Keep disk capture disabled for sensitive workloads. The dashboard has no login; do not expose it through a public reverse proxy. Diagnostic `.tar.gz` exports contain sanitized metadata, safe source still in memory or captured on disk, compressed text, and generated image artifacts. Data files and the database are local; protect backups and filesystem access. In passthrough mode, redaction affects storage/display only, never the upstream body.
